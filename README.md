# DuoFace

Dự án chuyển thương hiệu từ DuoNavi 1.0.3 sang DuoFace, giữ đầy đủ chức năng và cài độc lập với DuoNavi.

**Đầu mối bắt buộc để tiếp tục dự án:** [tiep tuc du an.md](./tiep%20tuc%20du%20an.md).

**Trạng thái 2026-10-11:** DuoFace 1.0.3-4 và 1.0.3-5 đã thử cài trên iPhone rootless nhưng `dpkg-query` báo `Status: install ok not-installed`; bản 1.0.3-6 chưa được kiểm thử thực tế. Không gỡ DuoNavi gốc, không tự ý loại bỏ thành phần của gói gốc. Cần kiểm tra đầy đủ metadata, chữ ký, script, đường dẫn và log cài đặt.

Các DEB thử nghiệm hiện chưa được upload vào repository. Không dùng README này làm xác nhận phần mềm đã hoạt động.
