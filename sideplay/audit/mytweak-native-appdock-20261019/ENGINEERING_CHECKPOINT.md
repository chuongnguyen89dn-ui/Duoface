## Implementation in candidate (code changes not proof of device fix)
1. **Native Dock owner source:** `MTNativeDockProbe.m/.h` runs **only in process CarPlay** via Logos `%ctor` and combined Theos `DFV1APreflight.plist` executable filter `SpringBoard, CarPlay`. It detects Apple's existing `DBDockWindow` (runtime only), swizzles only that class's `-layoutSubviews` to call **original implementation first** then READ geometry. Supplementary lookup uses `UIApplication.connectedScenes → UIWindowScene.windows`. It does not draw icons, manufacture a Dock, change Apple Dock window/frame/level, or link vendor library.
2. Publish **actual captured geometry** in `/var/mobile/Library/Preferences/com.duoface.mytweak.native-dock.plist`: process owner, source class, normalized CGRect X/Y/Width/Height, edge, timestamp, display aspect. Log to `/var/mobile/Library/Logs/MyTweakDock.log` via Filza. Only accept a real Dock-owned long thin window or Dock-named descendant anchored at a display edge (horizontal/vertical); no fixed 48pt/64pt constant. If native class/frame is missing, no fake values or UI mutations.
3. **Independent layout:** `MTDockLayout.m` validates record with timestamp <9sec, geometry/aspect ratio/edge and source origin; `MTBridgeCoordinator.m` stores original full frame and only clips its own `UIRootSceneWindow` to the area outside native Apple Dock. If reading fails/stale, retains previously working original full-size layout; if Zoom fullscreen, restores full frame. `MTBridgeRootViewController.m` and `MTSplitContainerViewController.m` expose Zoom status. Existing app-picking, 2 independent hosted scenes, gestures, resize, swap/close remain.
4. Control package ID unchanged `com.duoface.mytweak.v1a.preflight`, proposed `0.2.1~dock1`; rootless arm64/arm64e, no Conflicts/Replaces. Filename is a **candidate**, not proof of public Sileo availability.
