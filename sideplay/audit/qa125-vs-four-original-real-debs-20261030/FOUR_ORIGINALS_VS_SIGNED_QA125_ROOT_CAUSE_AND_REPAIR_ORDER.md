## 4. Repair order (ONLY source-grounded gates)

**Gate A — block new speculative release:** Sileo rollback to signed QA125 is already public and checksum-verified (publisher run `41013582309 SUCCESS`), though QA125 still has Play/Zoom failures. Do not run yet another experimental driver on the car. Do not alter Native12/DuoNavi/OmniCar or copy their code/licenses.

**Gate B — reproduce and record the SAME exact owner transition (without mutating scene):** On parked iPhone X iOS16.7.16, log package version, on-disk `DFTouchOwnerProbe.dylib` Mach-O UUID, actually loaded process UUID from IPS, scene ID/bundle/generation and `SBAppViewController` handle, callback `automatesLifecycle` and hosting, old/new foreground, transition source/caller (`DFUpdateScene` stack), and whether actual native CarPlay scene remained frontmost. Existing fatal reason proves GOFA scene `foreground=No` vs Live; new recorder must report **which guard** fails before observer Apple call and if scene is being replaced/closed. Differentiate true CarPlay Home vs phone screen-off.

**Gate C — first independent owner-lifecycle fix, not another magic flag:** Refactor first-party `DFSceneLifecycle` + `DFSceneHost` so only **one per-scene generation transaction owner** decides *when* Live host must end. **Stop modifying foreground in arbitrary global scene updates** when Apple owns the switch to Background; remove duplicated `setForeground:YES` policy from geometry-only resize (frame and reference only, gated by measured acceptance); defer/cancel remote frame updates on real lock/background/close; let foreign and stale scenes pass through Apple unmodified. The exact transition semantics and prevention of observer assertion MUST be validated with captured callback identity before shipping. Unit regression: owned/live, foreign, closing/stale, lock screen-off, Home, unplug, Zoom+Split, GOFA/YouTube simultaneously, no Apple callback suppress-all.

**Gate D — fix YouTube UI jitter at verified source:** Separate a low-cost state-lease heartbeat (if needed for validity) from expensive `layoutIfNeeded`, window frame resets, geometry requests. De-duplicate unchanged state (`sceneIdentifier,owner,generation,width,height,split,orientation`); refresh actual geometry only after stable ratio drag ends and scene readback changes, maintain orientation (QA90 verified). Avoid converting dynamic UI into snapshot. Add explicit raw divider gesture start/move/end and UI owner session sequence; do not claim ghost taps without matched touch logs.

**Gate E — restore missing accepted app-scene contract:** Use original per-app size policy as architecture only. One first-party owner should negotiate app logical size, UIKit view frame, scene frame and app-side active window; mark `accepted` only when independent receiver reports same generation/size/trait; throttle vs original. GOFA and YouTube must both survive lock, not just YouTube native orientation.

**Required physical release gates:** 1) signed macOS CI/source tests pass; 2) SHA-pinned signed DEB archive; 3) Sileo APT public SHA verified; 4) **installed package/dylib UUID matches artifact after Respring**; 5) parked iPhone two apps GOFA+YouTube, touch to Play with screen on/off, Zoom/Restore, splitter, CarPlay Home (must conceal), unplug (must release), reconnect (both apps restore), monitor SpringBoard SIGABRT. **Only 4–5 prove a real functional fix**.
