**Key conclusion:** `EnabledBundleIDs` selected on iPhone is a *choice/permission list*, not a command for native Home placement, not native scene launch and not pane assignment. Three independent failure hypotheses must be separated:
1. Missing **Apple system Home icon**: native entitlement/declaration existing but user's system CarPlay Customize roster hides it; DuoFace currently does not override that native roster. This is **supported directly by source design**, but actual user's CarPlay Customize state is unknown.
2. Missing icon **inside DuoFace App picker**: prefs unreadable/not persisted/notification missed, installed bundle ID mismatch or LS inventory filtered. Requires on-device prefs + picker log; no evidence yet to attribute a particular device cause.
3. App visible in picker but pane blank/boxed/not native map: phone `DFSceneHost` main-display app scene vs CarPlay native scene; separate scene ownership, real remote render and view geometry; GOFA previously showed this physically.
