## Branch-exact arithmetic / corrections

1. Original `gridCols` @`0xa40b0–a40cc` computes `candidate-4`, unsigned-compares with 2, and `csel x19,x8,x0,hi` with `x8=4`. Thus **valid 4,5,6 columns survive unchanged; otherwise columns=4**. Current source comments at DFAppPickerVC.m:175 incorrectly claim max 4, and `sizeForItemAtIndexPath:` hardcodes `width/4`.
2. Original `gridRows` @`0xa40d0–a40ec` uses `and x8,x0,#...fffe` / `cmp x8,#2` / `csel x22,x0,x8,eq`. Exact machine-level computation is **`rows = ((setting & ~1)==2) ? setting : (setting & ~1)`** (for nonnegative settings). This is NOT a safe claim of universal two-row layout; values outside valid settings range still need their configuration constraints traced. Current source hardcodes `collectionHeight/2`.
3. Original `hideIconLabels` is fetched from settings @`0xa40f0–a4100`, carried in `w25`, affects icon room @`0xa4488–a449c`, and branches past UILabel creation @`0xa50d4–a50dc`. Current displays names unconditionally.
4. Original `perPage=columns*rows` @`0xa4104–a4108`; it allocates scroll/paging behavior before drawing @`0xa4164–a4208` and page count includes count/perPage arithmetic @`0xa4118–a412c`. Do not rewrite count formula from only these instructions because the labeled Objective-C selector annotations for nearby indirect calls may be imprecise. Current `cardsPerPage=8` and app-source collection is independent.
5. **Tile grid horizontal** @`0xa43dc–a4440`: 6-column configuration uses nominal gap **8pt**, otherwise **10pt**; compact-card branch overrides intercolumn gap with **6pt**. Horizontal margin is **8pt** in compact mode or **14pt** otherwise. The intrinsic `tileWidth` is floor-to-single-precision of `(cardWidth - 2*horizontalMargin - (columns-1)*horizontalGap)/columns`. Compact threshold is loaded indirectly from Mach-O @`0xa43ec–a43f4`, needs exact VM value/threshold association before implementing breakpoint.
6. **Tile grid vertical** @`0xa4404–a447c`: card-height-compact branch selects vertical inset/row-gap **4pt** rather than **8pt**. `tileHeight=max(40pt, floor_f32((gridHeight - 2*verticalInset - (rows-1)*rowGap)/rows))`. `gridHeight` subtracts `contentY`, a page-indicator reservation (only when more than one page), and **2pt** from card height @`0xa4130–a4160`. The reserved indicator height branch is **14pt / 18pt** depending height threshold. This is **static arithmetic inference** grounded in register flow, not yet test-vector-verified UI frames.
7. Original tile placement @`0xa4db4–a4e48` decomposes index via signed divide and multiply-subtract using perPage and columns; horizontal and vertical stride come from `tileWidth+horizontalGap` and `tileHeight+rowGap` @`0xa4abc–a4ac8`. Precise final UIButton CGRect at each tested CarPlay size is still unproven because full frame origin/scroll-page offset needs traced.
8. Icon candidates @`0xa4480–a4938` depend on tile width/height, label visibility, columns, rows, and compact height; branches include machine immediates **38,42,48,58pt** (not a single max size), floor round and minimum **28pt**. Radius multiplier **0.225 × icon side** and selected icon border2pt/state colors are separately verified in `APP_TILE_STATES_VERIFIED_20261023.md`. The 38pt specialized path is from `0xa44b4–a44d4`.
