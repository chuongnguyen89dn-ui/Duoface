## CarPlay scene boundary — Apple official rules

- `CPTemplateApplicationScene` Apple docs: only navigation apps get `CPWindow` to draw actual map content, other categories only templates.
- `CPMapTemplate` Apple docs: overlays navigation controls; base map drawing is performed by navigation app in the CPWindow.
- Dashboard navigation scene is a **separate role** (`CPTemplateApplicationDashboardScene`), whose native map view must be supplied by participating navigation app.
- Source: https://developer.apple.com/documentation/carplay/cptemplateapplicationscene ; https://developer.apple.com/documentation/carplay/cpmaptemplate ; https://developer.apple.com/documentation/carplay/displaying-content-in-carplay .

**Architecture distinction (important):** hosting the regular iPhone scene of Maps/Google Maps in `SBAppViewController` does not guarantee you get the navigation app's actual CarPlay native map surface; it can yield the wrong instructions-only view or an unfocused phone scene. OmniCar's independent native split `SCPCarPane` and `isCarPlayApp:` detection indicate a likely separate native-app path. Need prove method calls/owners for `com.apple.Maps` and target Dashboard/CPWindow on a live device before implementing true dual-host native map — **do NOT forge `CPWindow` for another app, impersonate navigation entitlement or terminate native CarPlay Maps**.
