## Implemented independent corrections (no screen dim)

Otherwise it **calls original FBScene updateSettings exactly once** with unmodified incoming settings/context/completion and returns. Adds `incoming-background-passthrough no-current-carplay-host` diagnostic, not extra HOOK. This fail-closed behavior means it never suppresses a system background for foreign, invalid, Home-revoked, disconnected, or unknown owner. Does not force remote YouTube into foreground if proof is absent.
