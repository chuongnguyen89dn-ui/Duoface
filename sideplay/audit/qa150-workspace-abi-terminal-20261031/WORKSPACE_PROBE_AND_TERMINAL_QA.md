## What changed now

1. `sideplay/duoface-native-scene-host/DFWorkspaceABIProbe150.h` (commit `941f9d991afe9e8f15146e63d98bb06761983202`; Git blob `8e04998d78b2edaeb1a22ad7712e3f2a5acf42aa`) contains an **ABI-only, read-only** inventory. It records availability and exact Objective-C method type encodings using `class_getInstanceMethod`, `class_getClassMethod`, `method_getTypeEncoding`, and `DF144Log`. It never calls those methods, allocates private mutable workspace requests, deactivates any native app, writes new user settings or hooks a new method. It examines Dashboard `DBMutableWorkspaceStateChangeRequest`, `DBWorkspace`, `DBDashboardHomeViewController` and native Dock/Home methods, and SpringBoard `SBMainWorkspace`, `SBMainWorkspaceTransitionRequest`, `SBUIController`, `SBApplicationController` and `SBApplicationProcessState`. Missing selectors are logged as missing, **not** silently assumed to be interchangeable. Each finding has the request ID, bundle, display and process role, allowing same-request before/after comparisons on the real device.
2. `sideplay/duoface-native-scene-host/DFHomeStandalone144.m` (commit `2146eb2c4352732b320419c9c977d376e349f7e6`; Git blob `465af7edf30bc049fa5c9d14db71a990c961c0b1`) invokes this inventory only after a valid, user-enabled CarPlay selected-app request and an accepted SpringBoard request; no cold-start or all-app scanning.
3. Same file **fixes two real source-state gaps**. Terminal outcomes `failed` and `stopped` were previously overwritten in the same synchronous failure path (`sceneFailed -> reply failed -> stop -> reply stopped`); `emittedTerminal` now suppresses follow-on terminal writes *after a persisted terminal result*. A valid accepted request refused before the SB owner is installed previously returned `NO` without a result, forcing the CarPlay caller to wait until the ten-second watchdog; `DF150ReplyRejected` now emits exact matching `Version=2 / RequestID / BundleID / CarDisplayID / Outcome=failed / VerifiedPID=0`, but preserves a previous synchronous terminal for that request and never invents a hosted success.
4. `tests/test_qa150_workspace_preflight.py` enforces scope, absence of private workspace mutation, correct failure identity, terminal precedence and frozen scene-host Git blob. `.github/workflows/duoface-146-native-home-exit-private.yml` includes this test before building; `.github/workflows/duoface-qa147-mount-ready-guards.yml` includes it in the fast source gate.
5. The pinned original-route verification `sideplay/audit/qa147-full-route-evidence-20261031/verify_full_route_evidence.py` moved from21 to **23 historic/source/static assertions** (commit `dcbfcbe08844787ae44fd028a9012684efeadf2b`) including current first-party solo and ABI probe blob pins; CI workflow updated to23 (commit `349d114f0186785557e4f52d416293b044edc0cb`).
