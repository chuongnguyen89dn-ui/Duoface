## Source facts and original Native12 comparison
- `sideplay/duoface-native-scene-host/DFNative12Chrome.m` creates **four independent external UIRootSceneWindows** for app hosts with initial frames of one-quarter usable width, then repeatedly assigns each UIWindow and child bounds in `layoutControls`.
- `sideplay/duoface-native-scene-host/DFSceneHost.m` nests SBAppViewController remote scenes; `layoutScene` uses a logical 2x pane size and scales its UIKit host by one-half; post-attach private `FBScene updateSettingsWithBlock:` frame mutation is default OFF in .46 crash containment, but some contentReferenceSize setters remain.
- Original verified Native12 wiring documentation `sideplay/audit/native12-wiring-20261019/WIRING_REPORT.md` shows `CBBridgedSplitApp.layoutSplitViews` using a **shared CBWindow** with child app views; `handleDividerPan` updates one splitRatio, performs `layoutSplitViews`, and persists. App render/orientation also involves actual scene host owner, which we independently reimplement without third-party classes or licensing.
