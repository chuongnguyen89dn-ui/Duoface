## Native12 CBSlotPillView.updateBoundsSize — verified branch arithmetic

Original ARM64 IMP `0x85184`. A branch selects double-precision IEEE754 bit constants before the `setBounds:` call at `0x8522c`; `d0=d1=0`, `d2` contains width and `d3` contains height. The values below are therefore **actual setBounds dimensions in UIKit points**, contingent on three *unlabeled* state bytes read via ivar offsets `0xc58`, `0xc5c`, `0xc60`. Their semantic ivar names have NOT been confirmed.

| State branches (raw load offset) | Width if c60 flag zero | Height if c60 flag zero | Width otherwise | Height otherwise |
|---|---:|---:|---:|---:|
| c58 nonzero | 80pt | 22pt | 72pt | 19pt |
| c58 zero; c5c nonzero | 76pt | 22pt | 64pt | 19pt |
| c58 zero; c5c zero | 44pt | 22pt | 38pt | 19pt |

At `0x851b8/0x851c0` the constants are IEEE754 `72/80`; `0x851e8/0x851f0` are `64/76`; `0x851f8/0x85200` are `38/44`. `fcsel` at `0x85208` and `0x85214` chooses width/height based on the prior comparison with the c60 byte. `19` and `22` are directly encoded as `fmov` immediates. **76×22 is a verified branch but not proved universal.** 

Native12 `CBSlotPillView.pointInside:withEvent:` at `0x85348` calls `CGRectContainsPoint` after `CGRectInset(bounds,-8,-10)` (instructions `0x853b8–0x853ec`), expanding touch area 8pt horizontally and 10pt vertically. The exact alpha cutoff and how expanded outer touches reach child buttons still require an on-device test.

## Divider limitation and next evidence gate

Native12 `CBDividerView.updateGripLayout` IMP `0xff460` includes `fmov 30` and `fmov 28` at `0xff4c8–0xff4cc` plus complex relative-position and `setFrame:` arithmetic. These numeric immediates are **not enough to claim the true 36×44 or 44×36 UI control frame**. `CBDividerView.pointInside:withEvent:` IMP `0xff728` uses `CGRectInset` with branches around -12pt and -8pt, which also require owner/selector register tracing before changing QA hit areas.

The user must approve the visual and interaction parity from a real parked CarPlay receiver screenshot/runtime log for all eight layouts, app picker 4×2, pill focus/restore, status/Dock chrome, divider move/swap and exitMode stability. **ARM64 analysis, static tests and successful compilation are not device acceptance.**
