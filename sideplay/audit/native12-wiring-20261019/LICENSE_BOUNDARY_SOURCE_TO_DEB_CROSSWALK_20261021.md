## 3. Định nghĩa công việc cùng một đợt / một phát hành

Không phát hành Sileo sau từng file/chức năng. **Chỉ một bản tổng hợp** sau khi có: (a) Native12/DuoNavi 3-DEB audit PASS; (b) Objective-C clang/ldid/dpkg and Python tests PASS; (c) asset and singleton UI-owner check; (d) one live device test **video + thường + split + touch + swap + focus/Zoom + Home + reconnect + picker UI**; (e) nếu video Safe Mode vẫn còn, có .ips/stack chứng minh nguyên nhân, **không phát hành gói hứa đã khắc phục**.

**Giới hạn:** UI có thể tái tạo theo đúng quan hệ controller/method/function nhưng không có nghĩa có thể copy nguyên binary/license-coupled bridge. Original class methods và IMP address chứng minh đường gọi trong binary nguồn, không cho phép liên kết class vào package sạch chỉ nhờ đổi tên. Phần không có equivalent API phải thiết kế service độc lập rồi mới nối.
